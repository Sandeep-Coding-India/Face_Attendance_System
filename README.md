# Face Attendance System

Advanced Multi-Company Face Attendance Management System.

## Technology Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- PostgreSQL
- OpenCV
- Face Recognition
- HTML
- CSS
- JavaScript
- JWT Authentication

## Features

- Company Registration
- Company Login
- Employee Management
- Face Enrollment
- Live Face Recognition
- Attendance Management
- Check-In / Check-Out
- Attendance Reports
- Dashboard
- Secure Authentication
- Multi-Company Data Isolation

## Development

This project is being developed step-by-step with automated testing and Git version control.
